# HomeSplit — 家庭收支平台

單一 HTML 檔案的家庭收支／分帳工具，風格與操作參考 [KittySplit](https://www.kittysplit.com/)，可直接在瀏覽器開啟，無需建置、無需後端。

## 立即使用

1. 下載或 clone 本倉庫
2. 用瀏覽器開啟根目錄的 [`index.html`](./index.html)
3. 或啟用 GitHub Pages 後直接造訪網站

資料會自動存在瀏覽器的 **localStorage**，可離線使用。

## 主要功能

- **建立 Kitty**：名稱、貨幣（HKD／TWD／CNY／USD／EUR／JPY）、兩位參與者（名字可改）
- **收入與夾錢**：本月家庭總收入、共同夾錢（共用資金池）
- **支出紀錄**：金額、說明、日期、分類（膳食／日常用品／月費／其他）、付款人；支援編輯與刪除
- **即時計算**：每人總支出、分類總額、應收／應付、夾錢剩餘
- **Settle 結算**：計算淨收支（收入 − 總支出），顯示誰應付給誰；結算後開新月份並保留歷史
- **資料管理**：匯出 JSON、匯出 TXT 摘要、匯入還原、清除資料
- **加分功能**：歷史月份列表、淺色／深色模式、友善列印摘要

## 分帳邏輯

兩人平分共同支出（KittySplit 風格）：

- 每筆支出視為共同負擔，各付一半
- 若 A 實際多付，則 B 應付差額給 A（反之亦然）
- 夾錢剩餘 = 夾錢金額 − 總支出

## 技術說明

- 純 HTML + CSS + 原生 JavaScript
- 無框架、無外部 CDN 依賴
- CSS 變數集中在 `:root`，方便調整主題
- 響應式布局，支援手機與桌面
